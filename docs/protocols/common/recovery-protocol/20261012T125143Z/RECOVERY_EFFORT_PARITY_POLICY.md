# Recovery effort parity policy

Avoid cherry-picking. Equivalent evidence burden ≠ identical procedures.

## Common stages

S0 existing evidence · S1 public metadata recheck · S2 legal+artifact · S3 ZERO_COST · S4 fidelity · S5 resource · S6 preflight package · S7 human auth · S8 execution · S9 post classification.

## Shared rules

Same evidence hierarchy, no-inference, source authority, stop semantics, reporting fields, native/controlled split, ZERO_COST, test-seal protections.

Not required same: commands, runtime, training, architecture.

`RECOVERY_EFFORT_PARITY_SATISFIED` iff common stages + reporting burden applied.
