# Recovery evidence hierarchy

1 pinned repo artifact · 2 official release/tag · 3 author Zenodo/archive · 4 official model repo · 5 author docs · 6 paper supplement · 7 author package registry · 8 platform metadata · 9 third-party mirrors · 10 inference.

Lower cannot override contradictory higher.

Examples: HF MIT ≠ GitHub code license; Zenodo license ≠ GH HEAD without equivalence; paper ≠ missing implementation.
