# External ZERO_COST compute policy

Allowed: university/institutional infra without experiment-specific payment; lab server; already-owned machine; collaborator infra formally ZERO_COST.

Conditional: public academic grants if stable+reproducible.

Not primary: promotional cloud credit, trial GPU, commercial coupon, one-time free credit, undocumented borrowed environment.

Required metadata: CPU GPU VRAM RAM disk OS runtime access cost availability reproducibility owner class.
