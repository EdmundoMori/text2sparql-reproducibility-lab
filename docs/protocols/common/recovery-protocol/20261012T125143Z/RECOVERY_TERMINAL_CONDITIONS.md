# Recovery terminal conditions

| ID | Meaning |
|---|---|
| T_LEGAL | No public license covering relevant code/artifact |
| T_ARTIFACT | Essential artifact unavailable from public authoritative source |
| T_COST | Faithful execution intrinsically paid-only |
| T_RESOURCE | Faithful compute unavailable locally/documented ZERO_COST infra |
| T_DOMAIN | Cannot apply to common benchmark without destroying identity |
| T_RUNTIME | Historical environment not safely reproducible |
| T_EVALUATION | Output not observable under common protocol |
| T_REPRODUCIBILITY | Critical mutable dependency unpinnable |
| T_OTHER | Explicit evidence required |

Terminal ≠ scientifically invalid. Means not executable in relevant scope under current evidence.
